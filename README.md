# 💫 About Me:
👋 Hi, I’m Ammar<br><br>Software Engineer & Technical Publishing Professional ⚙️<br><br>I’m a software engineer focused on building scalable systems using TypeScript and Go, with Python in my toolkit for AI-driven workflows. My work centers on modern web development, developer tooling, and creating reliable, well-structured applications that balance performance with maintainability. I’m particularly interested in systems that improve developer experience and simplify complex workflows, and I actively build projects that deepen my understanding of real-world engineering challenges.<br><br>Alongside my engineering work, I bring a strong background in technical publishing as a LaTeX developer/typesetter, where I transform dense, highly technical manuscripts into clean, production-ready books. This experience—working with TeX/LaTeX workflows, complex math and code layouts, indexing, and bibliographies—has sharpened my attention to detail and my ability to structure complex information clearly. I currently contribute to production work with Manning Publications, and I see my career as a bridge between rigorous technical communication and hands-on software engineering.
